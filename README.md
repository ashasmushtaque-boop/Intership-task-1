A Python project for loading, exploring, and visualizing the famous Iris flower dataset using pandas, matplotlib, and seaborn.

****Overview****

This project demonstrates data analysis and visualization techniques on the Iris dataset, which contains measurements of 150 iris flowers from three different species: Setosa, Versicolor, and Virginica. The dataset includes four features: sepal length, sepal width, petal length, and petal width.

**Features**

Data Loading: Load the Iris dataset from CSV file
Data Exploration:
Display first few rows of the dataset
View dataset information and statistics
Statistical summary of all features

**Data Visualization:**

Scatter plots comparing different feature pairs (colored by species)
Histograms showing distribution of all features
Box plots for outlier detection in each numerical feature

Usage
Ensure the Iris.csv file is in the project directory
Open Iris_Dataset_Load_and_Visualization.ipynb in Jupyter Notebook or VS Code
Run the cells sequentially to:
Import necessary libraries
Load the dataset
Explore the data structure
Generate visualizations
Dataset

**The Iris dataset (Iris.csv) contains:**

150 samples
5 columns: Id, SepalLengthCm, SepalWidthCm, PetalLengthCm, PetalWidthCm, Species
3 species: Iris-setosa, Iris-versicolor, Iris-virginica
Visualizations

**1. Scatter Plots**

Three scatter plots showing relationships between:

Sepal Length vs Sepal Width
Petal Length vs Petal Width
Sepal Length vs Petal Length
Each plot uses color coding to distinguish between the three iris species.

**2. Histograms**

Distribution plots for all numerical features to understand the data spread.

**3. Box Plots**

Box plots for each numerical feature to identify potential outliers in:

Sepal Length
Sepal Width
Petal Length
Petal Width
